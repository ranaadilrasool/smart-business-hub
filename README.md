# 📊 Smart Business Operations Hub

A professional web-based dashboard designed to help small businesses manage clients, projects, tasks, deadlines, and budgets all in one place.

## 🚀 Features
- **Dashboard Overview:** Real-time summary metrics, project/task status charts, upcoming deadlines, and overdue task alerts.
- **Client Management:** Add, edit, search, and delete clients. Safely unassigns projects if a client is deleted.
- **Project Management:** Track project budgets, statuses, progress percentages, and deadlines. Link projects to specific clients.
- **Task Management:** Create tasks linked to projects. Automatically detects and highlights overdue tasks based on the deadline and status.
- **Reporting:** View total estimated budgets and download Project or Task data as CSV files for Excel.

## 🛠️ Technologies Used
- **Python** (Programming Language)
- **Streamlit** (Web Dashboard Framework)
- **SQLite** (Relational Database)
- **Pandas** (Data Analysis & CSV Generation)
